# Image prompts: Side case and Case 2

Every new image key used by the side case (`src/data/side01.js`) and Case 2 (`src/data/case02.js`), with its aspect ratio and a photorealistic prompt. Save each result as `public/assets/img/<key>.jpg`. Until a file exists the game shows a placeholder panel (`src/core/assets.js`), so nothing breaks while art is missing.

- **16:9** cinematic panels (openings and endings)
- **4:3** evidence photos. Every evidence prompt asks for the key item in the centre, so every evidence entry uses the hotspot `{ x: 0.5, y: 0.55, r: 0.13 }`. If a generated image puts the item elsewhere, edit `evidence.hotspot` in the case file (fractions of the photo width and height).
- **3:4** suspect portraits

Case 2 also reuses one existing Case 1 image: `intro_03_fire` (the 2021 fire flashback). It needs no new art.

59 new keys: side case 22 (9 cinematic, 10 evidence, 3 suspects), Case 2 37 (14 cinematic, 20 evidence, 3 suspects).
